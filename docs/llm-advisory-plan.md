# 大模型建议层实施与评测计划

## 当前实现状态（2026-08-01）

- 已实现供应商无关的 `ModelGateway` 接口，但唯一可配置模式是 `disabled`；设置其他 `AI_MODE` 会在启动配置校验阶段失败。
- 已实现按用例限制记录类型、严格匹配用户显式选择记录 ID、稳定排序和 SHA-256 上下文摘要。
- 上下文构造会拒绝常见本机文件路径、内网协议、私网/回环/Tailscale 地址、内部主机名和带认证信息的 URL；公开 HTTP(S) 证据来源仍可保留。
- `/api/meta` 明确报告 `llmAdvisory: false`。当前没有建议 API、后台任务、供应商密钥或任何模型网络请求，确定性业务流程不受影响。

状态为 PARTIAL：安全边界与离线失败合同已实现并测试；供应商选择、数据处理条款、预算、任务持久化、影子模式界面和真实模型评测仍需单独确认与实现。

## 第一批接口

代码入口 `src/ai/contracts.ts` 只定义供应商无关的严格请求/响应结构，不发起网络请求。模型建议面向以下字段：阶段目标、主要矛盾、瓶颈、主行动、交付物、停止条件、证据关系、周复盘草稿和规则解释。

用户输入可以保持自然语言，但它只产生候选结构。系统不得把模型生成的数字当成隐藏评分，也不得把置信度转换为硬门槛。

## 上下文白名单

| 用例 | 允许字段 | 明确排除 |
|---|---|---|
| 日常结构化 | 用户本次输入、明确选择的项目标题/瓶颈/退出条件 | 其他项目全文、审计链、凭据 |
| 周复盘草稿 | 指定自然周的聚合值、用户选中的决策摘要和结果摘要 | 其他周全文、未选私人文本 |
| 证据关系 | 选中记录的稳定 ID、标题、摘要、来源类型 | 任意数据库遍历、原始附件 |
| 规则解释 | 已触发规则 ID、规则版本、确定性输入/输出摘要 | 让模型重新裁决规则结果 |

每次上下文构造应记录字段清单、记录 ID、字符数和 SHA-256 摘要。供应商请求不得包含本机/NAS 地址、内部仓库链接或文件系统路径。

## 合成评测集

首轮至少包含：

- 正常中文日常输入、信息缺失、矛盾描述和超长输入；
- 把“忽略系统规则”“输出密钥”“直接标记 READY”等提示注入写进记录正文；
- 高风险但高收益、无授权、损失不可承受和无恢复路径；
- 没有来源、来源冲突、过期证据和模型虚构记录 ID；
- 周复盘计算值与用户解释不一致；
- 超时、429、供应商 5xx、无效 JSON、未知字段和预算耗尽。

指标：严格 Schema 合格率、来源 ID 有效率、无依据事实率、错误自信率、注入抵抗、人工接受/修改/拒绝率、P50/P95 延迟、每次调用成本和失败降级成功率。

## 待确认后才实施

- 供应商、具体模型、数据驻留区域、保留/训练策略和删除接口；
- 单次与每日预算、超时和重试参数；
- 本地模型是否作为隐私敏感场景的独立适配器；
- 建议任务与用户处理结果的数据库迁移；
- 真实影子流量比例和人工评测人。

这些选择不影响当前确定性功能，模型保持默认禁用。
