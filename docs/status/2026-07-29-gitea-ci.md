## 运行环境设计

- NAS 无法稳定访问 GitHub Actions 与 Docker Hub，因此 Gitea 工作流不在线下载 action，也不在每次运行时拉取通用工具镜像；
- `infra/ci/Dockerfile.gitea` 固定 Gitea 基础镜像 digest，并安装 Node 24、npm、GTK4、GJS、libadwaita、libsoup3、Xvfb、DBus、AT-SPI、ImageMagick、Noto CJK、Meson、Ninja 和 desktop 校验工具；
- CI 镜像只提供运行时，不复制源码、不嵌入访问令牌；
- checkout 使用本次运行的短期令牌和精确 commit SHA，令牌仅进入单条 Git 请求头；
- PostgreSQL service 使用 NAS 已有的 `timescale/timescaledb:latest-pg16` 镜像和一次性测试账号，不挂载生产卷。
