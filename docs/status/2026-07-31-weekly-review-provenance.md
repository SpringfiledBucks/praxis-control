# 周复盘统计来源与人工调整

状态：PARTIAL（本地共享合同已验证；真实 PostgreSQL 与 Gitea CI 待本提交验证）

日期：2026-07-31

## 整改范围

- 周复盘由模糊的“最近七天”改为明确的自然周 `[week_start, week_start + 7 天)`；
- 服务端在保存事务内重新计算决策数、闭环数和两个质量平均值，不再信任页面隐藏字段；
- 删除自由文本众数统计，页面只把本周最近一条正式记录作为矛盾和瓶颈的编辑起点；
- 用户可以修改报告统计，但必须保留系统计算快照、逐字段人工调整、调整原因和最终报告快照；
- 修改系统统计但没有原因时返回业务冲突，不写入周复盘；
- 重复保存同一自然周继续使用同一聚合 ID，审计链保持连续；
- 005 迁移、便携导出和事务导入携带三层统计来源。
