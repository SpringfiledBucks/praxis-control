# Praxis Control 0.2.0-beta.1

状态：PRE-RELEASE / 外部测试版

发布日期：2026-07-31

## 本次重点

- 本机服务改用操作系统动态回环端口，减少与其他固定端口服务冲突；
- Windows、Linux、Web、CLI 和 TUI 通过统一运行状态发现本机服务；
- 日常决策可以关联活动项目，并以稳定关系进入实践图谱；
- 新增“已计划 → 执行中 → 待复盘 → 已闭环”执行状态和取消边界；
- 首次结果必须从待复盘写入，结果修正会留下独立审计事件；
- 新增应用内使用教程，解释点数分配、风险硬门槛和结果评分；
- 项目 WIP、状态迁移和分析上下文由服务端事实强制执行；
- 轻量版继续使用 PGlite，全量版 PostgreSQL 合同已在 Gitea CI 验证。

## 下载选择

- Windows 11 x64：`PraxisControl-0.2.0-beta.1-win-x64.zip`；
- Linux x64/arm64 通用源码式运行包：`PraxisControl-0.2.0-beta.1-linux.tar.gz`。Linux 包不内置 Node.js 和 GTK 运行库。

两个发布包均附带 SHA-256 校验文件。Windows 包内置 Node.js 24 和自包含 WinUI 3 客户端；Linux 包需要 Node.js 24+、GJS、GTK4、libadwaita 与 libsoup 3。

## 升级与数据

升级前请先在旧版本执行 `praxis backup`，再安全关闭服务。程序包和事实数据目录相互独立，直接解压到新目录不会删除原数据；首次启动测试版时会自动执行 004 数据库迁移。

当前便携快照导入会严格校验迁移版本。004 之前导出的旧便携 JSON 不能直接导入本版本的空 PostgreSQL；需要先在对应旧版本恢复、升级，再重新导出。PGlite 数据目录的正常原地迁移不受此限制。

## 已知边界

- 这是供协作测试的预发布版本；
- macOS 尚未支持；
- Linux 原生 GUI 当前主要承担工作台和系统原生入口，完整业务流程可使用 Web；
- 轻量版本批次尚未实现跨设备自动同步；
- 高风险外部动作只分析、阻断和留痕，不自动执行。

发现问题时，请在公开仓库提交 Issue，并注明平台、操作步骤、预期结果、实际结果，以及 `praxis doctor` 中不含令牌的诊断输出。不要上传数据目录、运行状态文件、访问令牌或其他私人资料。
