# ADR-0010：大模型仅作为可审计建议层

状态：ACCEPTED（安全与业务边界） / PROPOSED（供应商、模型与生产参数）

日期：2026-07-31

## 决策

Praxis Control 的首批大模型能力只生成待用户处理的结构化建议。确定性规则、授权、损失承受、恢复路径、WIP、生命周期状态机和正式事实写入继续由现有领域服务决定。

首批用例限定为：

- 从自然语言中提取候选行动、交付物、停止条件和证据引用；
- 生成周复盘草稿；
- 建议证据或图谱关系；
- 解释已触发的确定性规则。

模型输出不得直接写入正式表、修改历史、决定硬门槛、调用外部工具或执行外部动作。用户接受、修改或拒绝建议后，仍须通过现有 Schema、事务、领域规则和追加审计。

## 合同

- Web/客户端只提交用例、明确选择的记录 ID 和可选用户指令，不提交任意数据库查询；
- `ContextBuilder` 按用例白名单读取字段、限制记录数和字符数，并把记录正文标记为不可信数据；
- `ModelGateway` 只接收已构造上下文，默认实现为 `disabled`，供应商适配器后续独立加入；
- 输出必须通过严格 JSON Schema；未知字段、额外评分、无法定位来源的事实和超限文本均视为无建议；
- 每条建议包含目标字段、候选值、依据记录 ID或“本次用户输入”标记、理由、分类置信度和不确定项；没有任何来源的建议拒绝进入结果；分类置信度不替代证据强度或业务评分；
- 模型调用不持有数据库事务。慢调用使用事实库中的任务状态，首版不新增 Redis；
- 传输失败与限流只做有限重试。超时、Schema 失败、预算耗尽和内容风险均安全降级，不阻塞确定性功能。

## 隐私与安全

- 浏览器、小组件和客户端不得持有供应商密钥；
- 默认不发送完整数据库、完整审计链、凭据、内部地址、文件路径和无关私人文本；
- 提示词、记录正文和模型输出都视为不可信输入，不能获得工具调用权；
- 日志保存供应商/模型标识、提示模板版本、输入记录 ID、脱敏上下文摘要或摘要哈希、输出、耗时、用量、错误码和用户处理结果，不记录密钥；
- 保留期限、数据驻留、供应商训练策略和删除能力在选型前必须确认；
- 高风险约束通过 Schema、权限、无工具网关、领域服务和审计强制，不依赖提示词自律。

## 状态机

```text
queued -> running -> succeeded -> pending_user
   |         |           |            |-> accepted
   |         |           |            |-> accepted_modified
   |         |           |            `-> rejected
   |         |           `-> expired
   |         `-> failed
   `-> cancelled
```

只有 `accepted` 或 `accepted_modified` 才能形成后续业务命令；业务命令失败时建议仍保留，不能把模型任务误标成正式写入成功。

## 上线门槛

1. 固定请求/响应合同、上下文白名单、脱敏规则和合成评测集；
2. 实现 `disabled` 网关和离线影子模式，核心功能在无模型配置时全部可用；
3. 使用合成或明确授权数据评测事实引用、Schema 合格率、错误自信、提示注入、延迟和成本；
4. 显式辅助模式必须展示来源、不确定项，并记录接受/修改/拒绝；
5. 未通过数据处理审查、预算上限、失败降级和审计验证前，不接真实私人数据；
6. 本项目不进入自动执行外部高风险动作阶段。

## 后果

模型可以降低自然语言整理成本，但不会成为新的事实源或规则引擎。首版会增加任务状态、上下文构造和审计成本；这些复杂度只在真实评测证明收益后才进入数据库迁移与在线供应商接入。
