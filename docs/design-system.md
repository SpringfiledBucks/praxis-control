# 前端视觉与交互基线

状态：ACCEPTED

日期：2026-07-28

## 定位

Praxis Control 是长期使用的工作工具。视觉层级服务于判断、录入和复盘，不以视觉刺激、动效或品牌展示争夺注意力。

## 约束

- 淡雅、实用、低饱和：以米白、墨绿、中性灰为主；红色和琥珀色只表示风险与警告。
- 内容优先：首屏必须先呈现当前状态、主要行动和下一步入口；装饰不得降低信息密度或可读性。
- 自适应：共享 Web 支持桌面、窄屏和触控入口；布局在 `900px`、`620px` 两级收束，表单和图谱不得形成页面级横向滚动。
- 克制的构成主义：通过网格、圆、线段、留白和比例建立秩序；允许圆锥曲线表达关系，但不使用高亮霓虹、玻璃拟态堆叠或持续动画。
- 可访问：键盘焦点清晰；遵循减少动态效果偏好；颜色不是状态的唯一载体。
- 框架中立：当前服务端渲染与原生 JavaScript 足以支撑 MVP。只有在复杂交互、组件复用或客户端状态显著增长时，才引入前端框架，并保持统一 API 与渐进增强能力。

## 几何语言

- 圆：稳定对象或图谱节点；
- 矩形与网格：输入、指标和工作区；
- 直线与箭头：明确流程；
- 二次贝塞尔曲线：对象间关系，曲率保持轻微，避免装饰性缠绕；
- 大字号衬线标题只用于页面定位，不进入高密度操作区。

## 验收

- 桌面与窄屏均能完成分析、保存、复盘、图谱和安全关闭；
- 无页面级横向滚动；
- 不依赖悬停才能发现核心操作；
- 关闭动画后功能与信息不缺失；
- 浏览器控制台无前端错误。
