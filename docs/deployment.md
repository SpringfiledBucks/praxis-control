# 部署说明

## 轻量版

```text
Windows/Linux Web、CLI、TUI
          → 127.0.0.1:4310
          → 本机 PGlite 数据目录
```

默认无需 `.env`。服务通过运行状态文件实现单实例、安全关闭和 CLI 发现；状态文件只允许当前用户访问。

关闭浏览器不会关闭服务。使用页面“安全关闭”、`praxis stop` 或平台快捷入口，服务会停止接收请求、关闭数据库并清理状态文件。

## 全量版

```text
多设备客户端
  → Tailscale/HTTPS + 认证
  → Linux/NAS 应用服务
  → 独立 PostgreSQL 数据库和低权限角色
```

NAS 当前因停电风险主动停服。恢复后必须先验证服务、证书、认证、数据库、备份恢复和访问边界，不直接把轻量数据切换过去。

## 提升迁移

轻量版升级全量版是一次受控迁移：备份 PGlite → 导出 → 空 PostgreSQL 迁移 → 导入 → 对账 → 切换事实源。MVP 不实现两个数据库长期双向复制。
