# Web/PWA 与 Windows 小组件使用说明

## 当前可用范围

Web 页面已具备 PWA 基础清单和离线状态页。正式使用必须通过可信 HTTPS；本机开发仅可利用浏览器对 `localhost` 的安全上下文例外。离线页不会缓存或展示决策正文，重新连通服务后再进入工作台。

在支持 PWA 的浏览器中，可从浏览器菜单或地址栏的安装入口把 Web 页面安装为独立窗口。当前只验证了代码和 HTTP 契约，尚未在正式 HTTPS 域名上完成安装验收，因此发布说明不得把它标为稳定可用。

## 小组件摘要

`GET /api/widgets/summary` 是供未来 Windows 11 小组件使用的最小只读摘要，并受现有登录认证保护。它只包含：

- 今日主行动；
- 今日计划可分配时间；
- 待复盘数量；
- 当前核心 WIP；
- 服务状态。

“今日计划可分配”来自用户填写的可支配时间扣除储备比例，它不是自动追踪的实时余额。小组件按钮只打开完整 Web 工作台或记录页，不直接写入正式事实。

当前 PWA 清单尚未注册 Windows `widgets` 成员。待公开 HTTPS 测试入口、合规截图、Windows 11 真机、登录失效恢复和可信分发全部通过后再启用。任何安装或排障步骤都不应要求关闭 Defender、SmartScreen、防火墙或第三方安全软件，也不应要求添加排除项。
