
## 分层

- `src/domain`：纯规则、Schema 和状态机；
- `src/application`：用例、事务边界和数据映射；
- `src/infrastructure`：PGlite、PostgreSQL、迁移、审计和备份；
- `src/web`：HTML/JSON 路由；
- `src/cli`：Windows/Linux 共通 CLI/TUI；
- `src/platform`：路径和平台适配；
- `src/runtime`：单实例与启停控制；
- `views` / `public`：共享 Web 客户端。

客户端可通过 `GET /api/meta` 读取 API 版本、规则版本、数据库后端和能力开关，通过 `GET /api/openapi.json` 读取机器可读合同；Windows/Linux GUI 不依赖页面结构推断服务能力。

轻量本机服务不承诺固定 TCP 端口。服务由操作系统分配动态回环端口，再以受当前用户保护的运行状态文件同步实际 URL 和控制令牌；所有本机客户端共享该发现机制，并统一使用运行时令牌调用版本化 API。全量部署仍通过显式固定端口接入反向代理，外部 Web 访问继续使用密码会话或可信身份头。

## 不变量

- 客户端不直接打开数据库；
- 轻量版无需 NAS 或外部数据库服务；
- 项目组合容量与日常分析上下文来自服务端事实和版本化规则，客户端显示值不构成写入依据；
- 日常决策关联项目时必须在事务内验证项目仍处于活动或维护状态，并创建稳定的有向图谱关系；
- “已闭环”不是可直接设置的状态，只能由待复盘结果写入产生；结果修正继续追加审计事件；
- 硬门槛先于评分；
- 正式分析绑定不可变输入、输出与规则版本；
- 历史通过追加事件纠正；
- 关系图谱节点使用稳定 ID；
- 生产、资金、权限和隐私类动作不自动执行。
- Windows 端不得以关闭或削弱 Defender、SmartScreen、防火墙或第三方安全软件作为安装、运行、更新、小组件或排障前提；被安全产品拦截时应安全失败并提供签名、哈希、来源和最小化诊断，不提供排除项或绕过指引。
